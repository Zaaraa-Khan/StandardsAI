# StandardsAI

## AI-Powered Indian Standards Recommendation Platform

StandardsAI is a user-friendly platform designed to help procurement teams identify relevant Indian Standards (IS) for products, technical specifications, and tender requirements.

### Features

- Product and procurement requirement input
- Tender document upload interface
- AI-powered standards recommendation interface
- Relevance and confidence indicators
- Recommended and related standards
- Standard details and status
- Tender compliance checking
- Certification and compliance information
- Procurement report generation
- Professional enterprise-focused UI

### Technology

- HTML
- CSS
- JavaScript
- GitHub Pages

### Project Status

The current version focuses on the frontend UI/UX. Backend services and AI-based recommendation functionality can be integrated in future development.
